# Your Playmate Sock Dolls Prototype

This is a working prototype eCommerce website developed as part of a Systems Analysis and Implementation course project. 

## Overview

- Warm, welcoming design aimed at families and children.
- Fully functional shopping cart and checkout simulation.
- No server/backend required — uses LocalStorage for cart persistence.

## Technologies Used

- HTML5, CSS3, JavaScript
- Visual Studio (local development)
- GitHub Pages (deployment)

## Features

- Browse products and add them to a shopping cart.
- Update quantity or remove items from cart.
- Calculate subtotal, sales tax (5.5%), shipping costs, and final order total dynamically.
- Confirm order via a simple confirmation page.
- Responsive layout for desktop and mobile.

## Deployment

Site is live on GitHub Pages https://okumanuk.github.io/yourplaymatesockdolls/.

## Notes

- No real payment processing is implemented — this is a front-end simulation only.
- Images and product descriptions are fictional for educational purposes.
